# Industrial yard surface

The surface layout is fitted around the unchanged factory buildings in
`factory_world_2026.9.22.sdf`. It uses 2K CC0 PBR textures from Poly Haven:

- Asphalt 02 by Rob Tuytel
- Concrete Pavement 02 by Charlotte Baglioni
- Sparse Grass by Amal Kumar

The source pages and texture JSON metadata are retained in the project download
sources. Open Robotics environment models used alongside this model are from
`osrf/gazebo_models`, licensed CC BY 3.0; their original author metadata is kept
inside each `model.config`.
